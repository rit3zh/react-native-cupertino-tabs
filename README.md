# react-native-cupertino-tabs

A customizable native iOS tabs and segmented control component for React Native.

## Installation


```sh
npm install react-native-cupertino-tabs react-native-nitro-modules

> `react-native-nitro-modules` is required as this library relies on [Nitro Modules](https://nitro.margelo.com/).
```


## Usage


```js
import { CupertinoTabsView } from "react-native-cupertino-tabs";

// ...

<CupertinoTabsView color="tomato" />
```
